## Authorship and provenance policy

1. Original text, project architecture, names, characters, artwork, music, audiovisual works, software, designs and documentation should retain creator/source metadata whenever practical.
2. Repository history must not be rewritten merely to remove earlier provenance. Corrections should normally be made through subsequent commits.
3. Third-party material must not be represented as original JPFR work. Licenses, permissions and source attribution should be retained where applicable.
4. Public descriptions intentionally document concepts without publishing confidential evidence, credentials, private personal information, unpublished manuscripts or security-sensitive implementation details.
5. Similarity between a third-party work and a project named here is not, by itself, proof of copying or infringement. Any infringement allegation should be assessed from verifiable evidence and, where necessary, by qualified intellectual-property counsel.

## Recommended evidence package

For important releases preserve: source file; creation/modification dates where reliable; SHA-256 hash; exported archival copy; repository commit SHA; authorship/credits; version number; relevant correspondence or agreements; and a redundant encrypted backup.
